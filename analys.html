Leaders and Laggards - Data Analysis

Purpose This Quarto document analyses how Sweden’s main industrial emitters engage with the Industry Leap and Climate Leap decarbonisation programmes.

It:

  1. Imports project, actor, emission, and ambition data from local files.

  2. Cleans and harmonises datasets.

  3. Examines emissions, engagement, and climate ambition (Analysis A).

  4. Maps technological pathways × emission scopes into clusters (Analysis B).

  5. Builds and analyses actor collaboration networks (Analysis C).

  6. Produces figures, tables, and metrics for use in the associated manuscript and appendix.

3 Identify main emitters from emission statistics and their engagement from collaboration data

In the next code chunk we first identify the 20 main emitters in Sweden by aggregating official emission statistics from Naturvårdsverket (2022). We then calculate their level of engagement in Industry and Climate Leap projects by aggregating collaboration data on public funding received. Finally, we merge the emissions and engagement data to establish the dataset used in Analysis A.

4 Analysis A: Ambition vs. engagement

We link firms’ stated climate ambition (Low/Medium/High) to their cumulative public funding (MSEK) to examine whether higher ambition corresponds to greater engagement in public decarbonization programes. We then cluster firms by emissions and engagement to reveal distinct participation profiles.

This analysis produces two figures that are used in the paper:

  1. Figure 2. Public funding engagement of main emitters by climate ambition level

  2. Figure 3: Clustering of main emitters

Ambitions are ordered from Low to High, while engagement is shown on a logarithmic scale to account for the skewed distribution of funding. 4.2 Clustering of main emitters

Since ambition levels alone do not explain variation in firms’ actual engagement, we apply a clustering analysis to identify distinct patterns. We use k-means clustering on two variables: each firm’s total annual emissions (ktCO₂e) and cumulative public funding received (MSEK). Both variables are log-transformed to reduce skewness.

The optimal number of clusters was determined using the silhouette and within-cluster sum of squares (WSS) methods, both pointing to three clusters. Figure 3 visualises the resulting groups (A1–A3), which represent different engagement–emissions profiles among the 20 main emitters.

4.2.1 Identifying appropriate number of clusters

# Prepare clustering input: log-transform emissions and engagement
cluster_input <- ambitions %>%
  mutate(log_ktco2 = log(ktco2),
         log_msek  = log(engagement_MSEK + 1)) %>%
  select(starts_with("log")) %>%
  scale()

# Assess number of clusters (silhouette + WSS)
fviz_nbclust(cluster_input, kmeans, method = "silhouette")
fviz_nbclust(cluster_input, kmeans, method = "wss")

# Apply k-means clustering with 3 centers (identified as optimal)
set.seed(42)
kmeans_result <- kmeans(cluster_input, centers = 3)

# Add cluster assignments to dataset
ambitions$cluster <- as.factor(kmeans_result$cluster)

5 Analysis B: Solution pathways and emissions scopes of investments

We map each main emitter’s public funding to solution pathways (e.g., Electricity & hydrogen, CCS, Recycling, Energy efficiency, BECCS, DAC, CCU, WtE‑CCS, Bio‑CCU, Biofuels & biomass, Other) and the emissions scopes they target (Scope 1–3, Infrastructure, Others). We then build a two‑mode network connecting emitters and pathway–scope combinations, with edge weights given by cumulative funding (SEK). The resulting layout and community detection (B1–B7) reveal how emitters concentrate funding across technological pathways and scopes.

6 Analysis C: Collaborations and Engagement

In the final step, we examine how main emitters are embedded in the wider network of actors participating in publicly funded decarbonisation projects. We construct a one-mode actor network in which nodes represent organisations (emitters and their collaborators), and edges capture co-participation in projects. This enables us to assess both the breadth of collaborative ties and the centrality of emitters in the network.

The first figure visualises the resulting actor network. Main emitters are highlighted and labelled, while other actors are coloured by type (e.g., industrial firms, universities, partnerships, intermediaries). Node size indicates degree centrality, and edge thickness reflects the number of shared projects. The network shows that while some emitters are highly central and well-connected, others remain more peripheral.

We then calculate a set of network statistics (e.g., density, clustering, average path length) to summarise structural properties of the collaboration network. To contextualise these measures, we compare the observed network with a null model of randomly generated networks with the same number of nodes and edges. This baseline allows us to assess whether the observed network exhibits higher clustering or shorter paths than expected by chance.

Finally, we cluster main emitters based on their collaborative embeddedness (degree centrality) and their level of public funding engagement (MSEK). The resulting groups (C1–C7), shown in the second figure, highlight distinct participation profiles ranging from “high collaboration and very high engagement” to “low collaboration and very low engagement.” These clusters illustrate how firms differ not only in the amount of funding they capture, but also in how embedded they are within collaborative structures.

6.3 Compare with random network

set.seed(1234)
# Use observed network size to parameterise the null model (G(n, m))
num_nodes   <- gorder(ig)
num_edges   <- gsize(ig)
iterations  <- 1000

# Initialize vectors to store results
avg_path_length <- numeric(iterations)
clustering_coeff <- numeric(iterations)

# Run the simulation for 1000 iterations
for(i in 1:iterations){
  # Generate random network with fixed nodes and edges
  g_random <- sample_gnm(n = num_nodes, m = num_edges, directed = FALSE, loops = FALSE)
  
  # Check if the network is connected; if not, take the largest component
  if (!is.connected(g_random)) {
    components <- clusters(g_random)
    largest_component <- induced.subgraph(g_random, which(components$membership == which.max(components$csize)))
  } else {
    largest_component <- g_random
  }
  
  # Compute metrics
  avg_path_length[i] <- mean_distance(largest_component)
  clustering_coeff[i] <- transitivity(largest_component, type = "global")
}

# Summarize results
results <- tibble(
  Metric = c("Average Path Length", "Clustering Coefficient"),
  Mean = c(mean(avg_path_length), mean(clustering_coeff)),
  SD = c(sd(avg_path_length), sd(clustering_coeff)),
  Min = c(min(avg_path_length), min(clustering_coeff)),
  Max = c(max(avg_path_length), max(clustering_coeff))
)

# Convert to gt table for display
results_tbl <- results %>%
  gt() %>%
  cols_label(
    Metric = "Metric",
    Mean   = "Mean",
    SD     = "SD",
    Min    = "Min",
    Max    = "Max"
  ) %>%
  fmt_number(columns = -Metric, decimals = 3) %>%
